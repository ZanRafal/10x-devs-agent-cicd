## Submission
Both badges are claimed through the same **certification form**, which appears
in the **last week of the course**, after module 5 releases, in the
[10xDevs Mission Log](https://platforma.przeprogramowani.pl/10xdevs-3/mission-log).
No fixed calendar date is published yet — watch the Mission Log. Keep all
artifacts (both architect artifacts and champion screenshots) ready to
paste/attach when the form appears.
